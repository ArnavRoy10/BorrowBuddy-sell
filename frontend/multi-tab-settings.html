⚙️ Multi-Tab Settings

Configure how the app behaves across multiple browser tabs

Multi-Tab Synchronization
When enabled, all changes in one tab will automatically sync to other tabs. When disabled, each tab can login as a different user independently.

💡 How to use different users in multiple tabs:

  • Option 1: Disable this setting (tabs work independently)
  • Option 2: Use different browsers (Chrome + Firefox)
  • Option 3: Use Incognito/Private mode + Normal mode
